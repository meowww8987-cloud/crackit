8 Design Decisions
1
Day Timeline Strip
A thin horizontal bar (10px) at the top of the card shows today's blocks as colored segments — Physics blue, Chemistry orange, Breaks hatched gray. A pulsing white "now" line with a glow shows where you are. Tap any segment to jump to that block's preview.
2
Big circular timer ring (64px)
Replaces the thin 2px linear bar. Shows elapsed vs total time as a colored arc with glow. Inside: large remaining time ("47m") + "left" label. Way more visceral — you instantly feel how much time is left.
3
Hero card with live glow
When a session is live for this block, the card gets a colored radial glow in the top-right, glowing border, and subtle gradient background using the subject's color. Same visual language as the redesigned SubjectSection.
4
"Live" chip with breathing dot
Replaces the aggressive red pulsing "LIVE" badge with a calm blue chip + breathing dot (same pulse-soft animation as SubjectSection's "Studying now" chip). Consistent visual language across the app.
5
Status badges row
Combines lateness + wasted time + remaining into a single row of small pill badges with colored dots: 🟢 On time / 🟡 N min late / 🔴 very late · ⚠ Nm wasted · Nm left. Replaces the scattered text rows in the current design.
6
Smart CTA — adapts to state
Idle → gradient "Start planned session" button. Live → Pause + Stop pair (orange + red). Wrong subject → "Switch to planned: Physics" warning CTA. No more guessing what to tap.
7
Next block preview card
A small recessed card at the bottom showing the next block: colored stripe + "Next at 4:00 PM" + subject + duration. Tappable to expand into a full preview. Way more present than the tiny "Next:" text line.
8
Quick actions row
Skip / Snooze 15m / Edit icon buttons. Skip = mark block as skipped (won't count against adherence). Snooze = push the start time by 15m. Edit = open Routine Builder. Real actions, not just an edit pencil.
✕ Problems with current CurrentBlockCard
No day context — can't see where this block sits
2px linear progress bar — invisible at a glance
LIVE badge uses aggressive red pulse
Lateness shown as scattered text rows
"Next:" is tiny forgettable text
Only an edit pencil — no real quick actions
Free time state has no stats or context
Wrong-subject warning is a yellow strip
No visual hierarchy — looks like an info card
